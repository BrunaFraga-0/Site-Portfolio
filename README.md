# 🚀 Projeto Site Portfólio - Bruna Fraga (em construção)

Este projeto é um site de apresentação pessoal desenvolvido como parte do processo seletivo e curso introdutório do programa **Carreira Tech (SCTec)**, uma iniciativa da **Secretaria de Tecnologia do Governo de Santa Catarina (SCTI/SC)** em parceria com o **SENAI/SC**.

O objetivo deste site é colocar em prática os conhecimentos adquiridos em Front-end.

---

## 💻 Sobre o Projeto

O site consiste em uma página de portfólio que apresenta minha trajetória, transição de carreira e habilidades técnicas. Foi estruturado utilizando boas práticas de **HTML5 Semântico**, garantindo melhor acessibilidade e indexação.

### ✅ O que foi implementado até agora:

- **Estrutura Semântica**: Uso de tags profissionais como `<header>`, `<nav>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<form>`.
- **Navegação por Âncoras**: Menu superior que leva o usuário diretamente para as seções "Sobre Mim", "Habilidades e Tecnologias", "Projetos" e "Contatos".
- **Seção Sobre Mim**: Texto sobre minha transição de carreira para a tecnologia e meus objetivos na área de tecnologia.
- **Softskills**: Uma seção lateral (`<aside>`) destacando minhas competências comportamentais como organização e proatividade.
- **Integração de Mídia**: Adição de foto de perfil com caminhos relativos.
- **Habilidades Técnicas**: Inicialmente estruturadas em tabelas, as habilidades foram refatoradas para um sistema de Cards com Grid Layout. Esta mudança foi visando uma interface mais limpa, visualmente amigável e moderna. A seção agora utiliza ícones (FontAwesome e Devicon) para facilitar a escaneabilidade técnica, separando as competências em: Stack Principal, Ferramentas, Fundamentos e Aprofundamento.
- **Formulário de Contato Completo**: Implementação de um formulário com campos de Nome, E-mail, WhatsApp, Assunto (menu suspenso), Área de Mensagem e Checkbox de autorização.
- **Links Interativos**: Botões diretos para WhatsApp, LinkedIn, E-mail e GitHub.
- **Formulário de Contato Inteligente:** Implementação de um formulário funcional integrado ao Formspree, permitindo o recebimento de mensagens diretamente no e-mail sem a necessidade de um servidor de e-mail próprio.

### 🎨 **Interface e Responsividade**

A interface foi construída utilizando CSS3 com foco em organização visual, legibilidade e experiência do usuário. 

Foram aplicados conceitos de:

- **Flexbox e Grid Layout**
- **Media Queries para responsividade**
- **Componentização visual com cards**
- **Tipografia moderna com Google Fonts**
- **Paleta de cores personalizada**
- **Feedback visual em elementos interativos**


### ⚙️ **Interatividade (JavaScript)**
- **Validação de Formulário:** Lógica para garantir que o nome tenha ao menos 3 caracteres, validação de e-mail via Regex e obrigatoriedade de campos.

- **Manipulação do DOM:** Script para abrir e fechar o menu sanduíche dinamicamente.
